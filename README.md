# Учёт тренировок

[![Build Status](https://github.com/Pavel19740404/ahj-steps/actions/workflows/deploy.yml/badge.svg)](https://github.com/Pavel19740404/ahj-steps/actions/workflows/deploy.yml)

🔗 **[GitHub Pages — Live Demo](https://Pavel19740404.github.io/ahj-steps/)**

## Описание

Приложение для учёта тренировок и прогулок в течение недели.

- Добавление записей: дата + км
- Сортировка по дате (новые сверху)
- Если дата уже есть — км суммируются
- Удаление строки по ✕
- Редактирование записи

## Запуск

```bash
yarn install
yarn dev
```
